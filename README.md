# Personal Portfolio Website

## Overview

This project is a personal portfolio website developed using HTML and CSS. The website presents my profile, skills, projects, and contact information in a clean and responsive layout. It serves as an online portfolio for potential employers, clients, and collaborators.

## Features

* Home page with personal introduction
* About Me page describing background and skills
* Projects page showcasing completed work
* Contact page with a contact form
* Responsive and user-friendly design
* Easy navigation between pages

## Project Structure


## How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/khuzaimah05/portfolio.git
```

2. Open the project folder.

3. Double-click `index.html` or open it using any web browser.

4. Navigate through the website using the menu links.
